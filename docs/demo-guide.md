# Demo 指南

这份文档回答三个问题：**演示什么、怎么演示、讲什么**。适用于客户演示、宣传片录制和对外介绍。

---

## 1. 一句话介绍

> **Private IM tool：私密、轻快、即时的即时通讯产品。** 文件全部存放在私有存储，不能直接公开访问，客户端拿到的是短期签名链接；Web 和 Android 实时互通；内置自研朋友圈；部署在 AWS 上，正按计划演进为全 Serverless 架构。

## 3. 推荐演示路线（约 8 分钟）

| 步骤 | 操作 | 观众会看到 | 讲解要点 |
|---|---|---|---|
| ① 登录 | 打开网页，输入账号登录 | 动效登录页：标题逐字出现、桃子吉祥物、右侧聊天预览自动播放。登录成功时彩纸飞散、卡片离场，首页侧边栏滑入、会话列表逐条错落出现 | 登录后**不刷新页面**，初始化和离场动画并行进行，从点击到看到会话列表约 1.1 秒（改造前 2.2 秒） |
| ② 实时聊天 | Ada 给 Dora 发几条消息，Dora 回复 | 气泡从左下 / 右下轻轻弹入；Dora 那边的会话**平滑移动**到列表顶部，未读角标弹出 | 两端实时同步；会话重排用了 FLIP 动画，不会突然跳动 |

| ⑤ 朋友圈 | 切到朋友圈 | 动态逐条浮现，九宫格悬停时轻微放大；点开九宫格里的图，会从方形裁切「展开」成完整画面，可以左右切换 | 自研朋友圈：写扩散时间线、可见性规则（共同好友才能看到彼此的评论） |

## 4. 产品特点

| 特点 | 说明 |
|---|---|
| **私密** | 文件存放在私有 S3：阻止公有访问、默认加密，由业务服务签发 1 小时有效的签名链接。客户端严格校验 HTTPS 证书。（预览接口的登录校验在待改进清单中，见 [交接说明](handover.md)） |
| **轻快** | 登录不刷新页面，登录到首页约 1.1 秒；会话、消息、图片都有过渡，没有闪烁；首屏约 1.3 秒 |
| **多端实时** | Web 与 Android 通过长连接实时同步消息、已读和朋友圈提醒 |
| **自研朋友圈** | 发布、点赞、评论与回复、互动消息、红点，Web 和 Android 两端都有 |
| **统一品牌** | 桃子吉祥物、紫色主题、Space Grotesk 字体、360 款自动生成的默认头像，Web 和 Android 风格一致 |
| **云原生** | 基础设施用 AWS CDK 管理；网页在 S3 + CloudFront，缓存在 ElastiCache，文件在 S3 |

## 5. 技术难点（讲给技术观众）

| 难点 | 我们怎么解决的 |
|---|---|
| **朋友圈的可见性** | 写扩散时间线保证读取快；读取时再按好友关系和黑名单二次校验；点赞和评论只对共同好友可见；回复的提醒也要先判断对方能否看到原评论，避免泄露隐私。44 项接口测试覆盖这些规则 |
| **实时提醒不重复、不复活** | 红点状态用「纪元号」：本地清零后，丢弃清零之前发出的刷新结果，避免旧数据把红点又带回来 |
| **私有文件又要快** | S3 单桶按类型分前缀，预览接口 302 跳转到签名链接，浏览器可以直接从 S3 / CloudFront 拉取；签名链接后面不能再追加参数，否则签名失效（踩过的坑） |
| **登录秒进首页** | 原实现登录后整页刷新，初始化做了两遍。现在登录返回后立即开始建连、同步，同时播放离场动画，动画结束时数据基本就绪 |
| **图片原位展开** | FLIP 动画加 `clip-path` 裁切：先把大图变换到缩略图的位置和形状，再过渡到全屏。九宫格的方形缩略图会「展开」成完整比例，而不是变形拉伸 |
| **列表重排不跳动** | 会话列表在更新前记录每项位置，更新后计算位移差，再过渡到新位置（FLIP） |
| **动画不破坏布局** | 只对 opacity / translate / scale / filter 做动画（走合成层）；容器上的动画不保留结束状态，避免内部弹出层（右键菜单、表情面板）定位错乱；尊重系统的「减少动态效果」设置 |
| **Android 适配挖孔屏** | 标题栏的状态栏占位改为读取系统真实高度。原来写死 40dp，在挖孔屏上右上角按钮会落进系统状态栏的触摸区，点不动 |
| **真机自动化测试** | AWS Device Farm 真机上跑 Appium 测试；服务器端配合脚本自动回复消息、自动给手机发的动态点赞评论，验证双向实时链路 |

## 6. 最值得秀的美观与丝滑细节

按「观众最容易注意到」排序：

1. **图片从缩略图原位放大**（聊天和朋友圈都有）：毛玻璃背景、玻璃质感工具栏，关闭时缩回原位。
2. **登录到首页的连贯过渡**：彩纸、卡片离场，首页逐层进入，中间没有白屏。
3. **会话列表平滑重排**：收到新消息时，会话滑到顶部，未读角标弹出。
4. **消息气泡弹入**：发出的从右下、收到的从左下，带轻微回弹。
5. **点赞粒子**：心形弹跳，周围飞出 5 颗彩色小爱心。
6. **图片由模糊变清晰**：加载完成后淡入，不会突然「蹦」出来。
7. **朋友圈逐条浮现、新评论滑入高亮**。
8. **品牌一致性**：桃子吉祥物出现在登录页、空状态和朋友圈封面；360 款「果园伙伴」头像；紫色主题贯穿 Web 和 Android。
9. **细节**：悬停才出现的细滚动条、紫色选中文字、键盘焦点环。

## 7. 演示注意事项

- 演示账号的聊天记录和朋友圈里有一些测试数据（如「Android 真机测试 #…」「Android 评论 #…」），录宣传片前可以用种子脚本重新生成。
- Android 的长连接直连 EC2 的公网 IP（`18100` 端口），实例重启后 IP 会变，需要更新配置（见 [部署文档](deployment.md)）。
- 环境是公开访问的，演示账号密码和固定验证码也是公开的，别人可能改动演示数据；需要时可按 [部署文档](deployment.md) 第 4 节临时开启访问密码。
